Shrinkit — browser-based image compressor

Solo project · live above

Live + open source

A free image compressor that runs entirely client-side using the Canvas API — no server, no upload, no sign-up. Built after repeatedly hitting "file too large" errors uploading photos to forms with strict size caps.

The problem

Most online compressors upload your photo to a server first — unnecessary for something a browser can already do.

The approach

Canvas API redraws and re-encodes the image client-side with an adjustable quality slider and live size comparison.

HTML / CSS / JS Canvas API Vercel
